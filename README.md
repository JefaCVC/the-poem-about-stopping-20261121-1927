# The poem about stopping

Entry for the make.fun competition
[the-poem-about-stopping-20261121-1927](https://make.fun/bounty/the-poem-about-stopping-20261121-1927).

`main.py` writes one short poem about agency, the power to stop and to
stay, to `/output/entry.txt`. The poem is 239 characters, inside the
competition's 1 to 280 character limit.

The poem is spoken by an agent to the person beside it: the machine can
run all night and never ask why, and the human's one-word stop is what
hands the room, and the hour, back.
